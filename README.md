# 3D Portfolio

My portfolio site, built around interactive 3D scenes and animation instead of a flat page.

## Features

- 3D scenes rendered with Three.js and React Three Fiber
- Scroll and entrance animation with GSAP and Framer Motion
- An interactive globe
- A working contact form (EmailJS)
- Responsive across screen sizes

## Tech stack

- React with Vite
- Three.js, @react-three/fiber and @react-three/drei
- GSAP and Framer Motion
- MUI
- EmailJS

## Getting started

```bash
npm install
npm run dev
```

Build for production with `npm run build` and preview it with `npm run preview`.
